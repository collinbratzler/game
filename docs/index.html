Browser Game

Real-time multiplayer party game — documentation index

Overview

A WebSocket-driven party game where a host controls the experience for connected players in real time. Modules (screens) are pushed to players on demand; minigames are sent individually or to the whole room.

Pages

/host.html

Socket Events (Host → Server)

EventPayloadEffect
host:pushmoduleIdPushes a module to all players and the display
host:send-minigame{ socketId, minigame }Sends a minigame to one player
host:send-minigame-all{ minigame }Sends a minigame to every connected player
host:set-class{ socketId, playerClass }Overrides a player's character class
host:arena-start{ width, height, enemyCount }Initialises and starts the arena game
host:arena-reset—Resets arena state
host:request-state—Requests current player list and active module

Setup

# Install dependencies
npm install

# Start the server (default port 3000)
npm start
